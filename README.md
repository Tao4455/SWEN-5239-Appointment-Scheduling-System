         
     Instructions to run my AptmtBooking program

       1.	Use Git Bash (Windows)
               Get to the project root, then
               Type:
        	 python -m venv venv
        	 source venv/Scripts/activate
        	uvicorn app.main:app –-reload

      2.	Copy:     http://127.0.0.1:8000/ui/1
                Paste it in your web browser.

     3.	Create or delete your appointments.
     4.	Shut down the program on your Git Bash when you are done.
